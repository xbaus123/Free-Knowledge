# Distributed and Client-Server Computing

*Chapter 1 · Part 7: Computing Environments.*

Once computers are networked, they can work together. That opens up two closely related environments.

## Distributed computing

A **distributed** system is a **collection of separate, possibly heterogeneous, systems networked together**. Heterogeneous means they can be different kinds of machines running different OSes.

A **network** is a **communications path** between them. **TCP/IP** is the most common protocol. Networks are grouped by the distance they cover:

| Network | Covers |
|---|---|
| **PAN**: Personal Area Network | The devices around one person: a phone and its earbuds |
| **LAN**: Local Area Network | A room, a building, or a campus |
| **MAN**: Metropolitan Area Network | A city |
| **WAN**: Wide Area Network | Countries, continents, the world |

A **network operating system** provides **features between systems across the network**:

- A **communication scheme** that allows systems to **exchange messages**.
- The **illusion of a single system**: users can work with files and resources on other machines almost as if they were local.

## Client-server computing

Early networks connected **dumb terminals** to a central computer. Those terminals have been **supplanted by smart PCs**. Now **many systems are servers, responding to requests generated by clients**.

```
                             ┌── client desktop
  [ Server ] ─── Network ────┼── client laptop
                             └── client smartphone
```

There are two common kinds of server:

- A **compute-server system** provides an **interface for a client to request services**: the client sends a request (for example, a **database** query), the server does the work and sends back the result.
- A **file-server system** provides an **interface for clients to store and retrieve files**.
