# Drill: Name That Category

*Chapter 2 · Part 4: Types of System Calls.*

A quick drill: each question names a system call, generic or real. Pick its category: process control, file management, device management, information maintenance, communications, or protection.

This quiz mixes multiple choice, true or false, and typed answers (10 questions). Each answer is checked as soon as you give it. Typed answers ignore capitals and extra spaces. A correct answer comes with a short explanation, and a wrong one costs nothing, so try again.
