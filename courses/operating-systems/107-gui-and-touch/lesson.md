# Graphical and Touch Interfaces

*Chapter 2 · Part 2: User Interfaces.*

Most people never type a command. They point, click, and tap.

## The GUI

A **graphical user interface (GUI)** uses a user-friendly **desktop metaphor**:

- Usually a **mouse, keyboard, and monitor**.
- **Icons** represent files, programs, actions, and so on.
- Pressing mouse buttons over objects causes actions: show information, offer options, run a function, or open a directory, known in a GUI as a **folder**.

The GUI was **invented at Xerox PARC** in the 1970s, then popularized by the Apple Macintosh in the 1980s.

## Most systems offer both

| System | Primary interface | The other one |
|---|---|---|
| Microsoft Windows | GUI | CLI "command" shell (and PowerShell) |
| Apple macOS | **Aqua** GUI | UNIX kernel underneath, with shells available in Terminal |
| UNIX and Linux | CLI | Optional GUIs: **CDE, KDE, GNOME** |

## Touchscreens

Phones and tablets needed something new, since a mouse is **not possible or not desired**:

- Actions and selection are based on **gestures** (tap, swipe, pinch).
- A **virtual keyboard** handles text entry.
- **Voice commands** are increasingly common.

## Which is better?

Neither. Power users and system administrators often prefer the CLI: it's faster for repetitive work and its commands can be saved in **shell scripts** (a batch interface). Most other users prefer a GUI. The choice is about the person, not the OS: the system calls underneath are the same.
