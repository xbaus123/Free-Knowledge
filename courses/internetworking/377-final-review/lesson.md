# Final Review: The Whole Course

*Wrap-Up · The Whole Course.*

The last quiz of the course: a few questions from every chapter, 1 through 11. Some will feel easy now that would have been impossible at the start. That's the point. If one stumps you, the explanation says which chapter to revisit.

This quiz mixes multiple choice, true or false, and typed answers (30 questions). Each answer is checked as soon as you give it. Typed answers ignore capitals and extra spaces. A correct answer comes with a short explanation, and a wrong one costs nothing, so try again.
