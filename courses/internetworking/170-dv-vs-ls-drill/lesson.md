# Drill: Distance Vector vs Link State

*Chapter 6 · Routing.*

Distance vector and link state side by side. Some questions use a new network: P–Q 2, P–R 6, Q–R 3, Q–S 7, R–S 1.

| Distance vector | Link state |
|---|---|
| No neighbor adjacency | Neighbor adjacency |
| Best route advertised | All known links advertised |
| Neighbor-aware only | Aware of the whole network |
| Slow convergence | Fast convergence |
| Timer-based updates | Event-triggered updates |
| Not scalable | Scalable |
| Low CPU usage | High CPU usage |
| Split horizon, route poisoning | Native routing loop prevention |
| Easy to configure | Complex to configure |
