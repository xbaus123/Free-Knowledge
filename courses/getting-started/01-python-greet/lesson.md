# Python: Greetings

Functions take inputs and **return** a value. In Python you define one with `def`:

```python
def double(x):
    return x * 2
```

Strings can be built with f-strings: `f"Hi {name}"`.

## Your task

Write `greet(name)` so that it returns `"Hello, <name>!"`.

- `greet("Ada")` → `"Hello, Ada!"`
- If `name` is empty, return `"Hello, world!"`.
